# Tienda D2

Tienda D2 es una página web de comercio electrónico inspirada en un supermercado
de precios bajos. Permite explorar productos por categorías, conocer las marcas
y promociones, consultar recetas y donar kits de alimentos a un banco de alimentos.

## GitHub
link: https://github.com/Manuel-Botk/Proyecto_Web_D2.git

## Características

- Banner principal con carrusel de imágenes
- Exploración por categorías
- Tarjetas de producto con marca, nombre y precio
- Sección de marcas, promociones y recetas
- Kits de donación

## Tecnologías

React, Vite, Tailwind CSS, React Icons

## Cómo ejecutarlo
    cd Tienda-D1
    npm install
    npm run dev

Luego abre http://localhost:5173 en el navegador.
